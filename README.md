# Factory Wars

Top-down RTS-achtige fabrieksgame in de browser: begin met handwerk (hout, steen, erts), automatiseer met mijnen, ovens, assemblers en transportbanden, breid uit met elektriciteit, chemie en treinen, en verdedig je groeiende fabriek met muren en torens tegen inheemse wezens die op vervuiling afkomen.

Status: opzet, nog geen speelbare versie. Startpagina: `index.html` (werkt via dubbelklik, geen server nodig).
